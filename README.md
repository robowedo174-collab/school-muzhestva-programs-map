# Карта программ и качеств Школы Мужества

Статический сайт для встречи руководителей 12 мая. Текущий формат интерфейса — одна полноэкранная таблица 49 качеств и модальная карточка качества по клику.

## Как открыть локально

1. Откройте папку `school-muzhestva-programs-map`.
2. Дважды кликните по файлу `index.html`.
3. Сайт работает через `file://`, потому что все данные находятся внутри `app.js`, без внешних библиотек, CDN и сборки.

## Структура

```text
school-muzhestva-programs-map/
  index.html
  styles.css
  app.js
  README.md
```

## Как редактировать данные

Все качества находятся в массиве `qualitiesData` в файле `app.js`.
Главная таблица строится из `blocks` и `qualitiesData`. Программы и цвета берутся из `programsData` и `programColors`. Возрастные вкладки в модальном окне строятся из `ageSteps`.

Текущая версия сайта работает в возрастной рамке `7-18 лет` по исходному документу «49 качеств мужчины». В основной возрастной лестнице и визуальной карте используются четыре этапа: `7-9`, `10-12`, `13-15`, `16-18`.

Этап `19-21` можно рассматривать отдельно как будущий слой взрослой интеграции, но в текущую версию карты он не включён, чтобы не выходить за рамку исходного документа.

В утверждённой системе используется 49 позиций с кодами `0.1`-`8.6`:

- `0` — ядро;
- `1` — духовное воспитание;
- `2` — морально-нравственное воспитание;
- `3` — воспитание характера;
- `4` — эмоциональное воспитание;
- `5` — физическое воспитание;
- `6` — интеллект и сознание;
- `7` — трудовое воспитание;
- `8` — социальное воспитание.

Рабочие педагогические понятия, которых нет в утверждённых 49 качествах, хранятся отдельно в `workingConcepts`. Они не входят в матрицу 49 качеств. Например, `Самостоятельность` сохранена как рабочее педагогическое понятие.

Чтобы добавить подробную карточку качества:

1. Найдите качество в `qualitiesData`.
2. Замените заготовки в полях `ages`, `events`, `notYet`, `programs`.
3. Поставьте статус `statuses.detailed`, если карточка методически заполнена.

Программы находятся в массиве `programsData`.

## Публикация через GitHub Pages

1. Создайте репозиторий на GitHub.
2. Загрузите в репозиторий содержимое папки `school-muzhestva-programs-map`.
3. В настройках репозитория откройте `Settings` -> `Pages`.
4. В разделе `Build and deployment` выберите:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
5. Сохраните настройки.

После публикации GitHub Pages откроет сайт из файла `index.html`.
